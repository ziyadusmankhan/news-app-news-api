News App Using API

A Python application that fetches the latest news articles from around the world using a news API.

Features
Search news by keyword
Retrieve real-time articles
Display headlines and descriptions
Easy-to-use command-line interface
Technologies Used
Python
Requests
News API
Installation
pip install requests
Usage

Run:

python main.py

Example:

Enter topic: Artificial Intelligence

The application will display the latest articles related to the topic.

Future Improvements
